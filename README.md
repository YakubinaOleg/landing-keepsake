# Keepsake — лендінг

Односторінковий адаптивний сайт дизайн-агенції **Keepsake**, зверстаний за макетом Figma «Keepsake — Responsive». У макеті є Desktop 1280, Tablet 768, Mobile 375, відкрите мобільне меню та окремий аркуш зі станами елементів.

**Демо:** https://yakubinaoleg.github.io/landing-keepsake/  
_(посилання запрацює після увімкнення GitHub Pages у налаштуваннях репозиторію)_

## Що використано

- **HTML5** із семантичними тегами: `header`, `nav`, `main`, `section`, `article`, `figure`, `footer`, `form`. На сторінці один `h1`, далі заголовки йдуть по порядку: `h2`, потім `h3`.
- **CSS3** без фреймворків і готових бібліотек. Стилі розділено на `css/reset.css` (скидання браузерних стилів) і `css/style.css` (все інше).
- **Шрифти** з Google Fonts: Oswald (300, 400, 700), Open Sans (300, 400, 700) і Dancing Script 700, із `font-display: swap`.
- **Іконки** — вбудований SVG-спрайт: набір `<symbol>`, які підставляються через `<use>`.
- **Зображення** у форматі WebP, з вказаними `width` і `height` та атрибутом `loading="lazy"`.
- **JavaScript** у проєкті відсутній.

## Як це зроблено

- **Змінні CSS.** Кольори, шрифти, відступи (`--space-*`) та розміри описані в `:root`. На планшеті й десктопі частина значень перевизначається в медіазапитах, тож у самих компонентах використовуються тільки змінні.
- **Mobile first.** Основні стилі написані під 375px (і коректно працюють від 320px), а для більших екранів додаються `@media (min-width: 768px)` та `(min-width: 1280px)`. Контейнер обмежений шириною 1100px плюс бічні поля й на широких екранах вирівнюється по центру.
- **Розкладка.** Скрізь використано Flexbox: послуги, статистика, клієнти, журнал, футер і шапка. Кількість колонок задає змінна `--cols`. Сітка робіт теж побудована на Flexbox (`flex-wrap` і `--cols`), CSS Grid не застосовується. Пропорції карток тримає `aspect-ratio` (1 : 0.72 на мобільному, 1 : 0.79 далі).
- **Мобільне меню без скриптів.** Кнопка з `popovertarget` відкриває блок з атрибутом `popover` (Popover API). Значок бургера змінюється на хрестик завдяки селектору `body:has(#site-menu:popover-open)`. Стан відкриття браузер відстежує сам, а в розмітці додатково прописані `aria-expanded` та `aria-controls`.
- **Фільтр робіт без скриптів.** Це приховані radio-кнопки, а картки відбираються селектором `:checked ~` за атрибутом `data-category`. На мобільному ряд кнопок-фільтрів прокручується вбік і виходить за правий край екрана.
- **Кнопка Load more.** Працює через прихований checkbox і `label`, які відкривають додаткові картки: на мобільному з 5 до 9, на планшеті з 8 до 9.
- **Наведення на картку.** З'являється оверлей з бірюзовим «+», назвою, червоною лінією та категорією. Цей самий вигляд вмикається при фокусі з клавіатури завдяки `:focus-within`.
- **Форма підписки.** Перевірку виконує сам браузер: поле `type="email"` і обов'язковий чекбокс. Помилка показується через `:user-invalid` разом із `:has()` та пов'язана з полем через `aria-describedby`. Повідомлення про успіх працює на `:target`, бо форма переходить на якір `#subscribed`. Справжньої відправки даних немає.
- **Фіксована шапка.** Має `position: fixed`, а в браузерах зі scroll-driven animations при прокручуванні стискається до 64px. Кнопка «нагору» завжди лишається на екрані.
- **Доступність.** Є помітний `:focus-visible`, посилання «пропустити до змісту», `aria-label` для кнопок без тексту, `<label>` для поля email та підтримка `prefers-reduced-motion`.

## Як запустити

Достатньо відкрити `index.html` у браузері. Також можна підняти локальний сервер, наприклад через розширення Live Server у VS Code.

## Структура проєкту

```
landing-keepsake/
├── index.html
├── css/
│   ├── reset.css
│   └── style.css
├── images/   (WebP)
└── fonts/    (порожня: шрифти підтягуються з Google Fonts)
```

## Додатково

- У макеті картки робіт і прев'ю статей журналу намальовано простими фігурами, тому файли в `images/` — це спрощені WebP-заглушки за тими композиціями. За потреби їх можна замінити на справжні зображення.
- Мобільне меню закривається хрестиком, клавішею Esc або кліком за межами меню. Оскільки скриптів немає, після кліку по пункту меню воно само не закриється.
